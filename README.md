# Наш слот 💖 — романтический Telegram Mini App

Слот-машина 777 без денег: каждый спин выдаёт приз из заранее заданного сценария.
Сценарий идёт один раз: после последнего спина кнопка блокируется, спины больше не запускаются.
При выигрыше слот отправляет боту приз, и бот присылает фото приза с поздравлением.

## Файлы

- `schedule.js` — **сценарий**: порядок выпадений и призы. Редактируй здесь.
- `index.html`, `style.css`, `app.js` — интерфейс и логика.

## Как поменять сценарий

В `schedule.js`:
- `PRIZES` — призы: название и иконка (`assets/prizes/*.svg`). Иконки нарисованы вручную, их можно заменить своими.
- `SCRIPT` — порядок спинов. Каждый элемент — три призовых id слева направо:

```js
{ symbols: ['coffee', 'coffee', 'coffee'] },  // выигрыш: все три совпали
{ symbols: ['p10', 'p50', 'p100'] },          // проигрыш
```

Если все три символа одинаковые, показывается окно выигрыша с текстом `WIN_NOTE`.
Иначе — `LOSE_TEXT`.

### Сообщение бота при выигрыше

В `bot/prizes.js` для каждого приза заданы фото (`assets/prizes/png/*.png`) и подпись.
Подпись к фото дополняется текстом «За получение приза обращайтесь к организатору».
Ключи (`p10`, `coffee` и т.д.) должны совпадать с `PRIZES` в `schedule.js`.

PNG-версии иконок сделаны из SVG (Telegram не принимает SVG). После правки SVG их нужно перегенерировать.

## Запуск локально

Открой `index.html` в браузере — всё работает без сервера.

## Подключение к Telegram (через бота)

Слот (фронтенд) лежит на GitHub Pages, а бот (`bot/bot.js`) отвечает на `/start`
кнопкой «🎰 Крутить слот», которая открывает слот внутри Telegram.

1. **Включи GitHub Pages:** репозиторий → Settings → Pages → Source: *Deploy from a branch*,
   ветка с файлами, папка `/ (root)`. Адрес будет примерно `https://<твой-логин>.github.io/777/`.
2. **Создай тестового бота** в [@BotFather](https://t.me/BotFather) (`/newbot`) и возьми токен.
3. **Запусти бота** (нужен Node.js 18+; компьютер или любой хостинг, где можно держать процесс запущенным):

   ```bash
   cd bot
   BOT_TOKEN=токен_от_BotFather WEBAPP_URL=https://<логин>.github.io/777/ npm start
   ```

   Токен задаётся только переменной окружения. Никогда не клади его в файлы репозитория.
4. Открой своего бота в Telegram и напиши `/start`.

GitHub Pages сам по себе не может держать бота запущенным, поэтому сам бот нужно запускать
где-то отдельно (свой компьютер, Render, Railway, fly.io и т.п.).

### Вариант: бот на GitHub Actions

Файл `.github/workflows/bot.yml` запускает бота внутри Actions.

- Settings → Secrets and variables → Actions:
  - **Secret** `BOT_TOKEN` — токен бота (сюда, а не в файлы).
  - **Variable** `WEBAPP_URL` — адрес слота на Pages.
- Workflow работает только с ветки по умолчанию: его нужно слить в default-ветку.
- Запуск вручную: Actions → Telegram bot → Run workflow. Дополнительно он стартует по расписанию каждые 30 минут.
- Ограничения: один запуск живёт до ~5.5 часов, между запусками бывают паузы. Telegram хранит
  непрочитанные сообщения 24 часа, так что они придут при следующем запуске, но на старые `/start`
  бот ответит с задержкой. Scheduled-запуски в публичном репозитории отключаются после 60 дней без активности.

## Важно про сюрприз

Сценарий лежит в открытом коде фронтенда, поэтому тот, кто откроет исходники страницы
или репозиторий, увидит порядок призов. Чтобы сюрприз сохранился:
- держи репозиторий приватным или сделай копию только с нужными файлами для хостинга;
- или перенеси `SCRIPT` на сервер (бэкенд с ботом), который отдаёт только текущий приз.

Прогресс (номер спина) хранится в `localStorage` браузера — на другом устройстве счёт начнётся заново.
